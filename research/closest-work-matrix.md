# MCRP Closest-Work Matrix

Status: bounded novelty evidence packet, not manuscript prose.  
Scope: primary papers, standards, and official project documentation verified 2026-08-16.

## Gate result

- **NO-GO:** MCRP is not novel if claimed broadly as a graph connecting scientific claims, evidence, executions, provenance, agents, or reviews. That territory is occupied in combination and, in several cases, within a single system.
- **CONDITIONAL:** A narrower contribution may be defensible: a **prospective, externally enforced, claim-versioned lifecycle** in which acceptance criteria and required approver roles are fixed before execution; claim transitions depend on immutable run evidence and independent checks; attestations are scoped, revocable, and invalidated by dependency changes; and records export to existing standards.

## Interpretation constraints

1. A graph data structure, claim/evidence nodes, provenance edges, agent identities, digital signatures, review stages, or executable packages are **not individually novel**.
2. A cryptographic signature establishes integrity and signer identity; it does not establish scientific correctness, reviewer independence, or adequate evidence.
3. A successful rerun establishes computational repeatability under recorded conditions; it does not by itself show that the output entails the scientific claim.
4. A contribution that merely combines the cited components is likely to be judged systems integration unless it supplies a new enforceable semantic contract and comparative evidence.
5. MCRP should extend or profile PROV/RO-Crate/nanopublications rather than introduce incompatible substitutes for their core concepts.
