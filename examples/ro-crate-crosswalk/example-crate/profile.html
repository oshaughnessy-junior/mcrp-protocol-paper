Local MCRP crosswalk transport profile 0.1

This is a synthetic, closed transport demonstration targeting RO-Crate 1.2. It is not a registered profile, a full validator, independent interoperability evidence, or scientific certification.

The metadata MUST contain the RO-Crate CreativeWork descriptor pointing to the root Dataset, with the versioned 1.2 context. Payload files MUST have matching declared SHA-256 and byte counts when this profile's payload verifier is run. All entities MUST have unique IDs and explicit types. Entity references MUST use JSON-LD @id objects.

The experimental namespace is https://example.org/mcrp/toy-crosswalk/0.1# . This reserved example-domain URI identifies local terms; it is not an operational ontology resolver. Claims use text, scope and requires; decisions use claim reference, declared actor, outcome, policy and validity tick; typed edges use source, target and kind. The root declares its release identity and references every claim, decision and edge. These fields MUST NOT be silently discarded on import. Unknown fields or unsupported contexts MUST cause this strict importer to reject the input.

An extension-unaware consumer may read title, description, date, license and file metadata. It MUST NOT infer MCRP scope, approval, currentness or invalidation behavior from those generic fields. Our projection emits a loss manifest and withdraws its local profile declaration.

The importer supports only the exact JSON shapes documented by crosswalk.py. It is not a general RDF-equivalence checker. No authority authentication, clock verification, scientific assessment, automatic carry-forward or hidden-dependency discovery is implemented.
