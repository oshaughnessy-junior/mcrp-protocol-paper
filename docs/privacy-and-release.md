# Privacy and release constraints

The working repository is private. A public artifact must not contain internal repository names, filesystem paths, operational topology, credentials, private issue content, personal data, restricted scientific material, or unverifiable anecdotes.

Before release:

1. copy only the minimum protocol and demonstration material;
2. replace private operational examples with synthetic or openly documented cases;
3. run an explicit secrets and path scan;
4. identify Codex and junior as the supplement authors and record any additional human editorial or release review accurately;
5. choose compatible documentation, code, and data licenses;
6. archive an exact release and bind review results to its digest.
