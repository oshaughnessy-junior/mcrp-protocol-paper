# MCRP distributed-review series seeds

These are substantial starting points for Parts 2–12, not approved posts. Each seed contains a publishable opening, one concrete example, an explicit boundary, and a transition. The sequence first completes the core MCRP lifecycle (Parts 2–4), then asks how exact review records could participate in distributed review (Parts 5–12).

A post is **mature** when it has a coherent 800–1,500-word argument, at least one worked example, verified primary-source support for consequential background claims, an explicit limitation section, a clean bridge to the next post, Codex/junior authorship, and no public-release placeholder or unsupported claim of originality, validation, adoption, or scientific authority.

Publication remains human-gated. Trust registries, transparency services, decentralized notifications, scholarly identifiers, content-addressed assertions, and publish–review–curate systems are guiding prior art. The candidate MCRP contribution is their disciplined integration with exact scientific releases, prospective claim contracts, scoped review attestations, dependency-sensitive freshness, and an event-driven automation loop.
